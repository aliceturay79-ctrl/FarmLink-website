# FarmLink – A Digital Marketplace for Local Farmers

## Project Overview

FarmLink is a responsive multi-page website designed to connect local farmers in Sierra Leone with customers who want to purchase fresh agricultural products.

## Project Objectives

* Help farmers showcase their agricultural products.
* Connect farmers with potential customers.
* Help customers discover fresh farm produce.
* Provide a website that works on desktop, tablet and mobile devices.

## Website Pages

1. Home – Introduces FarmLink and its main features.
2. About – Explains the background and purpose of FarmLink.
3. Services – Describes the services offered.
4. Products – Displays agricultural products.
5. Contact – Provides contact information.

## Technologies Used

* HTML5 – Website structure.
* CSS3 – Styling and responsive layouts.
* JavaScript – Include only if your website uses it.

## Responsive Design

FarmLink is designed to support desktop, tablet and mobile screen sizes.

## How to Run the Website

1. Download or clone this repository.
2. Open the project folder.
3. Find the `index.html` file.
4. Double-click `index.html` to open the website in a browser.

Keep all HTML, CSS, JavaScript and image files in their original folder structure.
