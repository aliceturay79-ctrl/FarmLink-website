# FarmLink – A Digital Marketplace for Local Farmers

## 1. Project Overview

FarmLink is a responsive multi-page website designed to connect local farmers in Sierra Leone with customers who want to purchase fresh agricultural products. The website helps farmers display their products and enables customers to explore available farm produce.

## 2. Project Objectives

* To provide an online platform for showcasing agricultural products.
* To help farmers connect with potential customers.
* To make it easier for customers to discover fresh farm produce.
* To provide a user-friendly website that works on desktop, tablet and mobile devices.

## 3. Website Pages

The FarmLink website contains five main pages:

1. **Home:** Introduces FarmLink and highlights its main features.
2. **About:** Explains the purpose and background of FarmLink.
3. **Services:** Presents the services offered through the platform.
4. **Products:** Displays agricultural products available to customers.
5. **Contact:** Provides contact information and a way for users to get in touch.

## 4. Technologies Used

* HTML5 – Website structure and content.
* CSS3 – Styling, layout and responsive design.
* JavaScript – Interactive functionality, where implemented.

## 5. Responsive Design

FarmLink is designed to support desktop, tablet and mobile screen sizes. Responsive layouts help users access the website across different devices.

## 6. How to Run the Website

1. Download or clone this repository to your computer.
2. Open the downloaded project folder.
3. Locate the `index.html` file.
4. Double-click `index.html` to open the website in your web browser.

For the best results, keep the HTML files, CSS files, JavaScript files and image folders in their original project locations.
